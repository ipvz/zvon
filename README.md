# Parley

Локальный ассистент встреч и диктовки для macOS. Всё распознавание — **на устройстве**,
без бота в звонке; данные и ключи не покидают Mac.

- **Встречи:** захват микрофона + системного звука (Core Audio taps) → расшифровка с ролями
  (Вы / Собеседник) → живые заметки, решения и задачи через LLM, ✦ Итог, вопросы по встрече (⌘K).
- **Диктовка (в духе Wispr Flow):** push-to-talk по одной клавише → вставка в активное поле или
  буфер, с опциональной AI-чисткой (убирает слова-паразиты, пунктуация, числа/проценты/время).
- **Задачи голосом:** «создай задачу…» / «напомни мне…» → LLM подтверждает и заносит в трекер.
- **Глоссарий:** локальная фаззи-коррекция терминов/имён + инъекция в промпт LLM.
- **Плавающий виджет + меню-бар:** запись, монитор диалога, быстрые задачи.

## Распознавание речи

**NVIDIA Parakeet TDT v3** через [FluidAudio](https://github.com/FluidInference/FluidAudio)
(CoreML → Apple Neural Engine). Мультиязычная, точный русский, ~200× realtime на Apple Silicon,
**полностью on-device**. Модель скачивается автоматически при первом запуске. Нарезка на
высказывания — собственный energy-VAD (адаптивный шумовой порог).

## LLM

Провайдер выбирается в настройках — **OpenAI · Anthropic · Ollama (локально) · Hugging Face ·
свой OpenAI-совместимый endpoint**. Ключи хранятся в **Keychain** (не в файлах). Без LLM запись
и диктовка работают; итоги/задачи/AI-чистка требуют подключённой модели.

## Сборка

```sh
brew install xcodegen          # один раз
xcodegen generate              # создать Parley.xcodeproj из project.yml
xcodebuild -project Parley.xcodeproj -scheme Parley -configuration Debug build
# или: open Parley.xcodeproj
```

**Подпись.** `project.yml` использует самоподписанную идентичность `"Parley Dev Cert"`
(стабильная подпись → TCC-разрешения не сбрасываются между сборками). На своей машине создай
такой сертификат в Keychain Access (Certificate Assistant → Create a Certificate, тип
*Code Signing*) **или** поменяй `CODE_SIGN_IDENTITY` в `project.yml` на `-` (ad-hoc).

**Упаковка в DMG:** `./scripts/package-dmg.sh` → `dist/Parley.dmg`. Для раздачи на другие Mac
без предупреждений Gatekeeper нужен Apple Developer ID + нотаризация (команды печатает скрипт).

## Разрешения

При первом запуске онбординг проведёт по: **микрофон** (запись/диктовка), **системный звук**
(вторая сторона звонка, macOS 14.2+), **Универсальный доступ** (авто-вставка + клавиша-триггер).

## Требования

macOS 14.0+ (захват системного звука — 14.2+), Apple Silicon рекомендуется.

## Стек

Swift · SwiftUI + AppKit · FluidAudio (Parakeet) · WhisperKit (только захват микрофона) ·
KeyboardShortcuts · EventKit · XcodeGen

## Структура

```
Sources/App    — точка входа, AppKit-контроллеры (меню-бар, виджет, HUD, hold-триггер)
Sources/Model  — движок ASR, пайплайн, VAD, LLM-клиент/провайдеры, сторы (сессии/задачи/глоссарий)
Sources/UI     — экраны (встреча, задачи, диктовки, глоссарий, настройки, онбординг), тема, компоненты
Sources/Util   — Keychain, вставка текста, разрешения, логи
Support        — Info.plist, entitlements
Resources      — иконка, шрифты
scripts        — упаковка DMG
```
